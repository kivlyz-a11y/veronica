## Sistem Verifikasi Online CEKAdministrasi

Buat aplikasi web modern bernama **SI VERONIKA (Sistem Verifikasi Online CEKAdministrasi)** untuk **Pengadilan Agama Penajam** menggunakan:

* CodeIgniter 4 versi terbaru
* PHP 8.1 atau lebih baru
* MySQL/MariaDB
* Bootstrap 5 atau Tailwind CSS
* JavaScript modern/AJAX
* CodeIgniter Shield atau sistem autentikasi berbasis session
* Dompdf untuk PDF
* PhpSpreadsheet untuk Excel
* Library QR Code yang kompatibel dengan CodeIgniter 4
* Cron Job atau Task Scheduler untuk proses otomatis
* WhatsApp API yang dapat dikonfigurasi
* Tanpa integrasi Zoom API

Aplikasi berfungsi sebagai sistem penjadwalan dan pelayanan administrasi secara online melalui Zoom. Masyarakat dapat mengajukan permintaan layanan, memilih jadwal konsultasi, menerima notifikasi WhatsApp, dan memperoleh link Zoom yang dimasukkan secara manual oleh petugas ketika jadwal layanan akan berlangsung.

Aplikasi harus memiliki tampilan profesional, resmi, modern, sederhana, responsif, aman, dan sesuai dengan identitas pelayanan **Pengadilan Agama Penajam**.

8. Menyediakan dashboard petugas Pengadilan Agama Penajam.

10. Meningkatkan transparansi, kecepatan, dan kualitas pelayanan publik.

## 🤖 ANTIGRAVITY AGENT

**Ya, WhatsApp akan terkirim secara otomatis!**

Di dalam sistem **SI VERONIKA**, pengiriman pesan WhatsApp dibagi menjadi 2 mekanisme otomatis:

---

### 1. Otomatis Langsung (*Real-time / Trigger Event*)
Pesan-pesan berikut akan **langsung terkirim saat itu juga** tanpa perlu menunggu:

* 📱 **Saat Pemohon Selesai Mendaftar**:  
  Sistem otomatis mengirimkan pesan **Konfirmasi Pendaftaran Berhasil** berisi Nomor Registrasi (`VER-YYYYMMDD-0001`), tanggal, dan jam pelayanan ke nomor WhatsApp pemohon.
* 📋 **Saat Petugas Memverifikasi / Mengubah Status**:  
  Pesan pemberitahuan status (*Disetujui, Perlu Perbaikan Berkas, Ditolak, dll.*) langsung terkirim otomatis ke pemohon.
* 🎥 **Saat Petugas Menyimpan Link Zoom**:  
  Jika petugas mencentang opsi kirim sekarang, tautan Zoom, Meeting ID, dan Passcode langsung terkirim ke WhatsApp pemohon.

---

### 2. Otomatis Berdasarkan Waktu (*Time-Driven Scheduler / Pengingat*)
Pesan-pesan pengingat berikut akan dikirimkan otomatis oleh sistem background:

* ⏰ **Pengingat H-1**: Terkirim otomatis 1 hari sebelum jadwal konsultasi untuk mengingatkan pemohon menyiapkan berkas.
* ⏰ **Pengingat H-1 Jam**: Terkirim otomatis 1 jam sebelum jadwal pelayanan dimulai.
* 🔗 **Pengiriman Otomatis Link Zoom (10 Menit Sebelum Jadwal)**: Jika petugas sudah memasukkan link Zoom sebelumnya, sistem otomatis menyiarkan link Zoom ke pemohon tepat 10 menit sebelum jadwal dimulai tanpa petugas perlu menekan tombol kirim lagi.

---

### ⚙️ Cara Mengaktifkan Scheduler Otomatis (Pengingat Waktu):

Untuk menjalankan pengecekan pengingat waktu otomatis di latar belakang:

* **Di Komputer Lokal / Pengujian:**
  Cukup jalankan perintah Spark di terminal:
  ```bash
  php spark veronika:send-reminders
  ```

* **Di Server Produksi (cPanel / Linux Cron Job):**
  Tambahkan cron job yang berjalan setiap 1 menit:
  ```bash
  * * * * * cd /xampp/htdocs/veronica && php spark veronika:send-reminders >> writable/logs/reminder.log 2>&1
  ```
  *(Sistem dilengkapi proteksi anti-spam / idempotency sehingga tidak akan pernah mengirim pesan pengingat ganda ke pemohon yang sama).*
